# Security

If you find a security problem in this bot or its Mini App, please report it privately through
GitHub: **Security → Report a vulnerability** on this repository. Please don't open a public issue.

Helpful things to include: what you found, how to reproduce it, and what someone could do with it.
I'll reply as soon as I can and let you know when it's fixed.

In scope: the code in this repository, the bot (`tgcloud/`) and the Mini App (`src/`).
Out of scope: Telegram itself, NEA's and LTA's data feeds, and the news sources the bot reads.
